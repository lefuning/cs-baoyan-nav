Python 基础（深度学习的前置）

深度学习几乎都用 Python 生态（NumPy / PyTorch）。先掌握最核心的语法和工具，再进入神经网络。

1. 为什么是 Python

  • 生态完善：NumPy（数值计算）、PyTorch / TensorFlow（深度学习框架）几乎都是 Python 接口。
  • 上手快：语法简洁，科研社区都用它，论文复现代码绝大多数是 Python。

4. PyTorch 入门：自动求导

PyTorch 的核心是张量（tensor）和自动求导（autograd）——后者其实就是自动帮你做反向传播：

import torch

x = torch.tensor([[1.0, 2.0]], requires_grad=True)
w = torch.tensor([[3.0], [4.0]], requires_grad=True)

y = x @ w                        # 1*3 + 2*4 = 11
loss = y.sum()

loss.backward()                  # 自动求梯度（反向传播！）
print(w.grad)                    # dloss/dw = x^T = [[1],[2]]
💡 和深度学习的联系

你后面学的"反向传播"，在 PyTorch 里只需一行 loss.backward()。理解原理 + 会用框架，两者都要有。

机器学习基础

深度学习是机器学习的一个子集。先建立机器学习的大框架，知道"问题长什么样"。

1. 什么是机器学习

传统编程是"人写规则"，机器学习是"从数据中自动学出规则"：给模型大量数据和一个目标（损失函数），它自己调参数。

2. 三大类学习

类型特点例子
监督学习有标签 (x, y)分类（垃圾邮件）、回归（房价预测）
无监督学习无标签聚类（K-Means）、降维（PCA）
强化学习通过奖励学习游戏 AI、机器人控制

3. 训练 / 验证 / 测试集

  • 训练集：用于训练模型参数。
  • 验证集：调超参数、选模型、早停。
  • 测试集：只在最后评一次，模拟真实泛化能力（绝不能碰）。

4. 经典算法速览

算法类型一句话理解
线性回归回归拟合一条直线，最小化 MSE
逻辑回归分类线性 + sigmoid，输出概率，用交叉熵
决策树分类/回归按特征不断 if-else 划分
SVM分类找最大间隔超平面，核技巧处理非线性
KNN分类看最近的 K 个邻居投票
K-Means聚类迭代分组，最小化类内距离
🔍 具体解释：线性回归怎么拟合

目标：找一条直线 $\hat{y} = wx + b$ 使预测尽量接近真实值。损失用 MSE：

$$ L = \frac{1}{n}\sum_{i}(y_i - \hat{y}_i)^2 = \frac{1}{n}\sum_{i}\big(y_i - (wx_i + b)\big)^2 $$

用梯度下降求解：对 $w$ 求梯度得 $\dfrac{\partial L}{\partial w} = \dfrac{2}{n}\sum x_i(\hat{y}_i - y_i)$，然后 $w \leftarrow w - \eta\dfrac{\partial L}{\partial w}$。

特例：最小二乘法有解析解（令导数为 0 直接解出 $w,b$），而梯度下降是迭代逼近——数据量大时梯度下降更常用。

🔍 具体解释：逻辑回归怎么做分类

线性回归输出连续值，不适合分类。逻辑回归在线性输出上套一层 sigmoid，把它压成 0~1 的概率：

$$ p = \sigma(wx+b) = \frac{1}{1+e^{-(wx+b)}} $$

$p \ge 0.5$ 判为正类，$p < 0.5$ 判为负类。损失用交叉熵：$L = -[y\log p + (1-y)\log(1-p)]$。

为什么叫"回归"却做分类？因为它拟合的是"对数几率" $\log\dfrac{p}{1-p} = wx+b$——本质是线性分类器，只能分线性可分的数据。

🔍 具体解释：决策树怎么选划分特征

决策树的核心是"每次选哪个特征切分最有效"，用信息增益（ID3）衡量：

$$ \text{信息增益} = \text{划分前熵} - \text{划分后加权熵} $$

熵衡量"混乱程度"：$H = -\sum p_k\log_2 p_k$。增益越大说明切分后子集越"纯"，越值得选这个特征。

例：10 个样本 6 正 4 负，熵 $H = -\frac{6}{10}\log_2\frac{6}{10} - \frac{4}{10}\log_2\frac{4}{10} \approx 0.97$。若按某特征切分后两边都变纯，熵降到接近 0，增益就大。

其他准则：C4.5 用信息增益率（避免偏好取值多的特征），CART 用基尼指数。

🔍 具体解释：K-Means 聚类怎么迭代

把数据分成 K 组（设 K=2），过程：

  1. 随机选 K 个中心

    随机选 2 个点作为初始质心。

  2. 分配

    每个点归到最近的质心那一类。

  3. 更新

    每类的质心更新为该类所有点的均值。

  4. 重复 2、3

    直到质心不再变化（或达到最大轮数）。

缺点：K 要预先指定、对初始点敏感（可能陷入局部最优）、对异常值敏感。改进：K-Means++（更好的初始化）。

5. 评估指标

  • 准确率 Accuracy：预测对的占比（类别不均衡时会失真）。
  • 精确率 Precision：预测为正的里面真正为正的比例。
  • 召回率 Recall：真正为正的里面被找出来的比例。
  • F1：精确率和召回率的调和平均，综合衡量。
🔍 具体解释：混淆矩阵

二分类的四种结果：

预测为正预测为负
实际为正TP（真正例）FN（假负例，漏报）
实际为负FP（假正例，误报）TN（真负例）
$$ \text{Precision} = \frac{TP}{TP+FP},\qquad \text{Recall} = \frac{TP}{TP+FN},\qquad F1 = \frac{2\times P\times R}{P+R} $$

场景选择：垃圾邮件过滤要求精确率高（别误删正常邮件）；疾病筛查要求召回率高（别漏掉病人）。二者往往此消彼长。

🔍 具体解释：偏差、方差与正则化

模型误差可分解为三部分：偏差（欠拟合，模型太简单）、方差（过拟合，对训练数据太敏感）、噪声（不可避免）。

$$ \text{总误差} = \text{偏差}^2 + \text{方差} + \text{噪声} $$

模型简单 → 高偏差低方差；模型复杂 → 低偏差高方差。目标是找到平衡点。

正则化抑制过拟合：损失加惩罚项 $\text{Loss} + \lambda R(w)$，其中：

  • L1：$R(w)=\sum|w_i|$，产生稀疏解（很多权重为 0，可做特征选择）。
  • L2：$R(w)=\sum w_i^2$，让权重整体变小但不为 0（权重衰减）。

6. 机器学习 vs 深度学习

传统机器学习
  • 需要人工设计特征（feature engineering）
  • 数据量较小时也有效
  • 可解释性强
深度学习
  • 自动学特征（特征表示学习）
  • 需要大量数据 + 算力
  • 端到端、效果好但可解释性弱
🧭 第 0 步

学习总览：抓住深度学习的主线

深度学习本质是：用多层神经网络拟合从输入到输出的映射，通过梯度下降自动学习参数。

🧩 三大核心要素（记住这条主线，后面全是细节填充）
  1. 模型（Model）

    神经网络长什么样——它决定了"函数空间"有多大、能表达多复杂的映射。从感知机到 Transformer 都是模型结构的演进。

  2. 损失函数（Loss）

    怎么衡量"学得好不好"——定义了一个可优化的目标，把"学得好"变成一个数值。

  3. 优化算法（Optimizer）

    怎么更新参数让损失变小——梯度下降及其变体，是模型"学"起来的动力。

📌 学习建议

不要一上来背公式，先建立"模型 → 损失 → 优化"的骨架，遇到任何新模型都往这三个框里套，你会发现自己理解速度明显变快。

🧠 第 1 步

神经网络基础：神经元、激活函数、损失

一切模型的起点。理解单个神经元如何工作，以及"非线性"为什么至关重要。

1.1 神经元与感知机

单个神经元对输入 x 加权求和加偏置，再过激活函数：

$$ y = f(Wx + b) $$
  • 感知机（Perceptron）：最原始的线性分类器，只能解决线性可分问题。经典反例是 XOR 问题——感知机无法拟合，这直接推动了多层网络（MLP）的诞生。
  • MLP（多层感知机）：输入层 → 隐藏层 → 输出层，中间必须有非线性激活函数，否则多层线性叠加仍是线性变换，堆多深都没意义。
⚠️ 面试考点

为什么需要激活函数？ 引入非线性，否则无论堆多少层，整体仍是输入的线性函数，表达能力受限（等价于单层）。

1.2 常用激活函数对比

函数公式优点缺点
Sigmoid$\dfrac{1}{1+e^{-x}}$平滑、可解释为概率饱和区梯度消失、输出非零中心
Tanh$\dfrac{e^x-e^{-x}}{e^x+e^{-x}}$零中心仍有饱和问题
ReLU$\max(0,x)$计算快、缓解梯度消失、稀疏激活神经元死亡（负区间梯度为 0）
Leaky ReLU$x\lt0$ 给个小斜率解决死亡问题需调参数
GELU概率式加权Transformer 默认激活计算稍贵
Softmax归一化为概率分布多分类输出层必备不用于隐藏层

1.3 损失函数

  • 回归任务：MSE $\quad L = \dfrac{1}{n}\sum_i (y_i - \hat{y}_i)^2$
  • 分类任务：交叉熵 $\quad L = -\sum_i y_i \log \hat{y}_i$
💡 为什么分类用交叉熵而不用 MSE？

Softmax + 交叉熵组合的梯度形式非常漂亮（$\hat{y} - y$），不会因输出接近 0/1 而梯度消失；而 MSE + Sigmoid 在饱和区梯度趋近 0，训练极慢。

🔍 具体解释：softmax 为什么要减去最大值

设某样本的 logits 为 [1000, 1001, 1002]，直接算 $e^{1000}$ 会溢出成 inf（超出浮点范围），结果变成 nan。

解法：先减掉最大值 1002，得到 [-2, -1, 0]，再算：

$$ e^{-2}=0.135,\quad e^{-1}=0.368,\quad e^{0}=1.0 \quad\Rightarrow\quad \text{softmax} \approx [0.09,\ 0.245,\ 0.665] $$

因为 softmax 是"比例"，分子分母同除以 $e^{1002}$ 不改变结果，却把指数压到安全范围。这就是"数值稳定版 softmax"的原理。

🔁 第 2 步

反向传播：深度学习的发动机

核心就是链式法则：损失对某层参数的梯度，等于从输出层一路乘回来的梯度乘积。必考手推

2.1 手推流程（两层网络为例）

  1. 前向传播

    算出每层的线性输出 $z^{(l)}$ 和激活值 $a^{(l)}$。

  2. 输出层误差

    $\delta^{(L)} = \nabla_a L \odot f'(z^{(L)})$

  3. 逐层回传

    $\delta^{(l)} = (W^{(l+1)T}\delta^{(l+1)}) \odot f'(z^{(l)})$

  4. 参数梯度与更新

    $\dfrac{\partial L}{\partial W^{(l)}} = \delta^{(l)} a^{(l-1)T}$，然后 $W \leftarrow W - \eta \dfrac{\partial L}{\partial W}$

🔍 具体解释：一个数值例子看懂反向传播

设最简单的网络：输入 $x=2$，目标 $y=4$，初始权重 $w_1=1,\ w_2=1$，损失用 MSE。

  1. 前向

    隐藏层 $z_1 = w_1 x = 2$，激活 $a_1 = \text{ReLU}(z_1)=2$；输出 $\hat{y}=w_2 a_1=2$；损失 $L=(\hat{y}-y)^2=(2-4)^2=4$。

  2. 输出层梯度

    $\dfrac{\partial L}{\partial \hat{y}}=2(\hat{y}-y)=-4$，于是 $\dfrac{\partial L}{\partial w_2}=\dfrac{\partial L}{\partial \hat{y}}\cdot a_1=-4\times 2=-8$。

  3. 隐藏层梯度

    $\dfrac{\partial L}{\partial a_1}=\dfrac{\partial L}{\partial \hat{y}}\cdot w_2=-4\times 1=-4$；又因 $z_1>0$ 有 $\text{ReLU}'(z_1)=1$，故 $\dfrac{\partial L}{\partial w_1}=\dfrac{\partial L}{\partial a_1}\cdot 1\cdot x=-8$。

  4. 更新

    设学习率 $\eta=0.1$：$w_1 \leftarrow 1.8,\ w_2 \leftarrow 1.8$。权重都变大，输出从 2 逼近目标 4。

关键直觉：梯度为负说明"输出偏小，要把权重调大"；每个参数的梯度都是"它对损失的影响"逐层用链式法则累乘而来。

2.2 梯度消失 / 梯度爆炸（高频）

链式法则连乘：若每层梯度 < 1，深网络梯度指数衰减 → 梯度消失（深层参数几乎不更新）；若 > 1，指数爆炸 → 梯度爆炸。

🛡️ 缓解手段

ReLU 激活、残差连接、BatchNorm / LayerNorm、梯度裁剪（clip）、合理初始化（Xavier / He）。

⚙️ 第 3 步

优化器：让模型"学"起来

梯度算出来了，怎么用它更新参数？不同优化器决定收敛速度与稳定性。

优化器更新方式特点
SGD$W \leftarrow W - \eta g$简单，但收敛慢、易震荡
Momentum累积历史梯度方向物理惯性，加速收敛、抑制震荡
Adam一阶矩 + 二阶矩每个参数自适应学习率，工程最常用（Transformer 标配）
🔍 具体解释：梯度下降一步步怎么走

设损失 $L(w)=w^2$，初始 $w=3$，学习率 $\eta=0.1$。梯度 $\dfrac{dL}{dw}=2w$，更新 $w \leftarrow w - \eta\cdot 2w = 0.8w$：

步数当前 w梯度 2w更新后 w
03.06.02.4
12.44.81.92
21.923.841.536
………→ 0

每次沿负梯度方向走一小步，$w$ 逐步逼近最小值 0。若学习率太大（如 $\eta=1$），$w$ 会在 3 和 -3 间震荡发散——这就是"学习率要合适"的原因。

💡 Adam 的 warmup

Adam 前期需要 warmup（学习率先小后大），因为二阶矩估计初期偏差较大。这是 Transformer 训练的重要细节。

👁️ 第 4 步

CNN 卷积神经网络：理解 Transformer 的重要背景

CNN 是"局部 + 权重共享"思想的典范，它的残差结构被 Transformer 原样继承。

4.1 核心概念

  • 卷积：卷积核在输入上滑动做内积，参数共享（一个核到处用）+ 局部连接（只看感受野内），大幅减少参数量。
  • 池化：MaxPool / AvgPool，降维、扩大感受野、提升平移不变性。
  • 经典网络：LeNet → AlexNet（ReLU + Dropout）→ VGG（小卷积核堆深）→ ResNet（残差连接）。
🔍 具体解释：卷积怎么算

3×3 输入、2×2 卷积核，步长 1、无填充，输出是 2×2：

输入：          核：
1 2 3         1 0
4 5 6         0 1
7 8 9

第一个输出 = 1×1 + 2×0 + 4×0 + 5×1 = 6
滑到下一格 = 2×1 + 3×0 + 5×0 + 6×1 = 8
以此类推得输出：  6   8
               12  14

卷积核在输入上"滑动"做内积，同一个核扫遍整张图——这就是参数共享：无论输入多大，参数只有核里那 4 个。

4.2 ResNet 残差

$$ y = F(x) + x $$

让网络至少能学"恒等映射"，解决深层网络退化问题。这个"加一条短路"的思想，正是 Transformer 里残差连接的来源。

🔗 第 5 步

RNN → LSTM → Seq2Seq：Transformer 的直接前身

处理序列数据的经典路线，理解它的缺陷才能理解 Transformer 为什么被发明。

5.1 RNN

每个时刻共享同一套权重：

$$ h_t = \tanh(W_{hh}h_{t-1} + W_{xh}x_t + b) $$
  • 训练用 BPTT（随时间反向传播），本质还是链式法则。
  • 致命问题：长序列梯度连乘 → 梯度消失，学不会长距离依赖。

5.2 LSTM（记熟，面试常考）

引入细胞状态 $C_t$（信息高速公路）和三个门：

$$ f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f) \qquad \text{遗忘门} $$ $$ i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i) \qquad \text{输入门} $$ $$ \tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C) $$ $$ C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t $$ $$ o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o), \quad h_t = o_t \odot \tanh(C_t) \qquad \text{输出门} $$
门作用
遗忘门 $f_t$决定丢掉多少旧信息
输入门 $i_t$决定写入多少新信息
输出门 $o_t$决定输出多少当前状态
🔍 具体解释：用"记笔记"类比三个门

把细胞状态 $C_t$ 想成一本"长期笔记"，每个时刻 LSTM 做三件事：

  • 遗忘门 $f_t$：翻看旧笔记，决定划掉哪些不再重要的内容（$f_t$ 接近 0 表示遗忘）。
  • 输入门 $i_t$：把当前新信息（候选 $\tilde{C}_t$）写进笔记多少。
  • 输出门 $o_t$：从笔记中提取多少内容作为当前输出 $h_t$。

例子：句子「我昨天去了北京，___」。预测空格时，LSTM 需要"记住" 北京 和 昨天（保留在 $C_t$），同时遗忘无关信息。正是这条贯穿始终的"高速公路" $C_t$，让信息能跨越长距离而不像 RNN 那样衰减。

5.3 Seq2Seq（编码器-解码器）

Encoder 把整个源序列压成一个固定长度向量，Decoder 再逐步生成。

⚠️ 瓶颈问题

所有信息挤在一个向量里，长句子信息丢失——这正是注意力机制要解决的痛点。

🎯 第 6 步

注意力机制：一切的转折点

与其只依赖最后一个向量，不如让 Decoder 每一步直接"看"源序列的每个位置，按相关性加权取信息。

缩放点积注意力（核心公式）

$$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V $$
  • Query（查询）："我要找什么"
  • Key（键）："我有什么可被匹配"
  • Value（值）："匹配后给什么内容"

流程：Q 与每个 K 点积求相似度 → 除以 $\sqrt{d_k}$ → softmax 归一成权重 → 对 V 加权求和。

🔍 具体解释：一个翻译例子

翻译「我 喜欢 猫」→ 生成英文 I 时，Decoder 当前词是 I：

  • Query = I 的查询向量（"我在找什么信息"）。
  • Keys = 「我」「喜欢」「猫」三个词的键向量。
  • 点积算相似度（示意值）：与"我" = 0.8，与"喜欢" = 0.3，与"猫" = 0.1。
  • softmax 归一成权重：[0.60, 0.30, 0.10]。
  • 加权求和：0.60×v(我) + 0.30×v(喜欢) + 0.10×v(猫)。

结果里"我"占大头，所以模型输出 I 而不是 like 或 cat。这就是注意力：不依赖固定向量，而是按相关性动态聚焦。

⚠️ 面试必问：为什么要除以 $\sqrt{d_k}$？

当 $d_k$ 很大时点积数值变大，softmax 进入饱和区（梯度趋近 0）。理论上若 q、k 各分量独立且均值为 0、方差为 1，则点积方差为 $d_k$，除以 $\sqrt{d_k}$ 后方差归一为 1，让 softmax 保持合适梯度。

🚀 第 7 步

Transformer 详解（核心）

2017 年《Attention Is All You Need》提出，彻底改变 NLP 格局。必考核心最高频

7.1 整体架构

Encoder-Decoder 结构：

📥 Encoder（N 层）
  • 多头自注意力（Multi-Head Self-Attention）
  • 前馈网络（FFN）
  • 各带残差 + LayerNorm
📤 Decoder（N 层）
  • Masked 多头自注意力
  • 交叉注意力（Q 来自 Decoder，K/V 来自 Encoder）
  • FFN

7.2 多头注意力（Multi-Head Attention）

把 $d_{model}$ 维的 Q/K/V 切成 $h$ 个头（原论文 $h=8$），每个头独立做注意力，最后拼接再过 $W^O$：

$$ \text{MultiHead}(Q,K,V) = \text{Concat}(head_1, \dots, head_h)\, W^O $$

作用：每个头关注不同表示子空间（语法、指代、位置等），相当于多个注意力视角的集成；每个头维度减半，计算量不显著增加。

7.3 位置编码（Positional Encoding）

自注意力是集合操作（打乱顺序输出不变），不含顺序信息，必须显式注入位置：

$$ PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right) $$ $$ PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right) $$

为什么用 sin/cos？ 不同频率让不同维度编码不同尺度位置；$PE_{pos+k}$ 可由 $PE_{pos}$ 线性变换得到，利于学相对位置；数值有界、可外推到更长序列。

加分：可学习位置嵌入（BERT） 加分：RoPE 旋转位置编码（LLaMA） 加分：ALiBi
🔍 具体解释：位置编码长什么样

取 $d_{model}=4$（4 个维度），位置 pos=0 和 pos=1 的编码：

位置维度0维度1维度2维度3
pos=0sin(0)=0cos(0)=1sin(0)=0cos(0)=1
pos=1sin(1)≈0.84cos(1)≈0.54sin(0.01)≈0.01cos(0.01)≈1.0

可以看到：越靠前的维度变化越快（高频），越靠后的维度变化越慢（低频）。这些编码向量直接加在词向量上，让模型感知到词的位置；不同维度不同频率，使近距离和远距离的位置差异都能被区分。

7.4 FFN + 残差 + LayerNorm

  • FFN：$FFN(x) = W_2 \cdot \text{GELU}(W_1 x + b_1) + b_2$，中间维度放大 4 倍，逐位置共享，提供非线性与更大参数空间。
  • 残差连接：解决深层梯度消失，梯度直通。
  • LayerNorm：对每个样本的特征维做归一化。
⚠️ 为什么用 LayerNorm 而不用 BatchNorm？

① BN 依赖 batch 统计量，序列长度可变时不稳定，训练/推理不一致；② LN 每样本独立归一化，不受 batch 大小与序列长度影响；③ 自注意力对数值尺度敏感，LN 稳定训练、允许更大学习率。

7.5 Decoder 的两个 Mask（常考）

  • Padding Mask：遮掉 padding 位置，避免无效位置参与注意力。
  • Look-ahead Mask（因果掩码）：生成第 $t$ 个词时只能看到前 $t-1$ 个位置，防止"偷看未来"。实现：上三角置 $-\infty$，softmax 后概率为 0。

7.6 Transformer vs RNN（高频对比）

维度RNN / LSTMTransformer
并行性必须逐时刻串行完全并行（一次看到全部输入）
长距离依赖梯度消失，难捕捉注意力直接连任意两位置，$O(1)$ 路径
计算复杂度单步 $O(d^2)$，串行 $n$ 步自注意力 $O(n^2 d)$，可并行
位置信息天然有时序需要位置编码
💡 长序列的痛点与解法

自注意力 $O(n^2)$ 是长序列瓶颈 → 衍生出稀疏注意力、线性注意力、FlashAttention（IO 优化，LLM 标配）等。

一、数学基础

线代特征值 / 特征向量的几何意义是什么？▼
$Ax=\lambda x$，特征向量是在 $A$ 变换下只伸缩、不改变方向的向量，伸缩倍数即特征值。应用：特征值分解、SVD 在 PCA 降维、矩阵低秩近似中的核心地位。
微积分泰勒展开有什么用？▼
用多项式逼近复杂函数。关键理解：梯度下降本质是一阶泰勒展开——沿负梯度方向函数值下降最快。
优化拉格朗日乘子法是什么？▼
带等式约束的极值问题，构造 $L = f + \lambda g$，令梯度为 0 求解。它是 SVM 推导的核心。
概率极大似然估计（MLE）？为什么 MSE 和交叉熵都能从 MLE 推出？▼
MLE 是找参数使观测数据出现概率最大。假设误差服从高斯分布 → 最大化对数似然等价于最小化 MSE；假设类别服从类别分布 → 等价于最小化交叉熵。这是损失函数的概率视角。
概率大数定律 vs 中心极限定理？▼
大数定律：样本均值收敛于期望；中心极限定理：大量独立同分布随机变量之和近似正态分布。
概率条件概率与贝叶斯公式？▼
$P(A|B)=\dfrac{P(B|A)P(A)}{P(B)}$，刻画先验/后验/似然的关系，是朴素贝叶斯分类器的基础。

二、机器学习基础

泛化过拟合是什么？怎么解决？▼
训练好、测试差。解决：更多数据、正则化（L1/L2）、Dropout、早停、数据增强、降低模型复杂度。
正则L1 和 L2 正则化的区别？▼
L1 产生稀疏解（把不重要权重压到 0，可做特征选择，几何上是菱形角点）；L2 让权重整体变小但不为 0（圆形，权重衰减 Weight Decay）。
统计偏差-方差权衡？▼
偏差高 = 欠拟合（模型太简单）；方差高 = 过拟合（太复杂）。两者此消彼长，需要找到平衡点。
评估K 折交叉验证怎么做？▼
数据分 K 份，轮流取 1 份做验证集、其余做训练集，跑 K 次取平均。比单次划分更可靠，充分利用数据。
模型SVM 的核心思想？▼
最大化间隔（找到使两类间隔最大的超平面）；核技巧把低维非线性问题映射到高维线性可分。
模型逻辑回归 vs 线性回归？▼
逻辑回归输出概率、用 sigmoid + 交叉熵，用于分类；线性回归输出连续值、用 MSE，用于回归。
数据样本不平衡怎么办？▼
重采样（过采样/欠采样）、调整类别权重、Focal Loss、阈值调整。
聚类K-Means 流程与缺点？K 怎么选？▼
随机初始化中心 → 分配样本 → 更新中心 → 迭代。缺点：需预设 K、对初始点敏感、非凸。K 选择：肘部法则、轮廓系数。

三、深度学习基础

手推手推两层神经网络的反向传播？▼
见上文"反向传播"章节的 4 步流程：前向 → 输出层误差 → 逐层回传 → 梯度更新。务必能在白板上默写。
激活为什么 ReLU 比 Sigmoid 好？▼
缓解梯度消失、计算快、稀疏激活；缺点：神经元死亡（负区间梯度为 0，可用 Leaky ReLU 缓解）。
优化Adam 有什么缺点？▼
可能不收敛到最优（二阶矩估计问题）、需要 warmup；后期可用 SGD 微调提升泛化。
正则Dropout 的原理？▼
训练时随机丢弃神经元，相当于训练多个子网络的集成；测试时乘 $(1-p)$ 保持期望一致。
归一化BatchNorm 的作用和原理？▼
对 batch 内样本归一化，缓解内部协变量偏移，允许大学习率；训练用 batch 统计量、推理用滑动平均（这是它与 LN 的重要区别）。
CNNCNN 感受野怎么算？▼
逐层累加：$RF_l = RF_{l-1} + (k-1)\prod_{i \lt l} s_i$，其中 $k$ 为核大小、$s$ 为步长。
CNN1×1 卷积的作用？▼
通道升降维、跨通道信息融合、减少参数（等价全连接，如 ResNet 瓶颈结构）。
模型ResNet 为什么有效？▼
残差结构让梯度可以"抄近路"直接回传，缓解梯度消失；且网络至少能学恒等映射，避免退化。
训练学习率怎么调？▼
warmup、阶梯衰减、余弦退火；太大震荡不收敛、太小收敛慢。

四、Transformer 深度追问（拉开差距的关键）

核心Q、K、V 分别是什么？为什么需要三个？▼
Q 是当前词的查询，K 是供匹配的键，V 是被提取的内容，三者来自同一输入的不同线性变换。若 Q=K 只有一种匹配模式；三分开让"匹配方式"与"输出内容"解耦，才能支持多头多样化的匹配。
核心为什么除以 $\sqrt{d_k}$？▼
点积方差随 $d_k$ 增大，softmax 进入饱和区梯度消失；除以 $\sqrt{d_k}$ 把方差拉回 1，保持合适梯度。
核心多头注意力相比单头的优势？▼
多个子空间、多视角，不显著增加计算量（每头维度减半）。
核心为什么需要位置编码？▼
自注意力是置换不变的（排列等变），不含时序信息，必须显式注入位置。
核心为什么位置编码用 sin/cos？能否用 one-hot？▼
sin/cos 有相对位置线性关系、数值有界、可外推。one-hot 能但无法泛化到长序列、维度爆炸。
核心Transformer 与 RNN 的复杂度对比？▼
自注意力 $O(n^2 d)$ 可并行 vs RNN $O(nd^2)$ 串行；Transformer 优势在并行、劣势在超长序列。
核心Decoder 为什么要 masked self-attention？▼
自回归生成时不能看到未来 token，否则信息泄漏。
核心LayerNorm vs BatchNorm，为什么 Transformer 选 LN？▼
LN 每样本独立归一化，不受 batch 大小和序列长度影响，训练/推理一致；BN 依赖 batch 统计量在变长序列下不稳定。
核心残差连接的作用？▼
缓解梯度消失、让深层可训练、信息直通。
核心BERT 和 GPT 的区别？▼
双向 vs 单向、MLM vs 自回归、理解 vs 生成、Encoder vs Decoder。
进阶【加分】RoPE / KV Cache / FlashAttention / MoE？▼
  • RoPE：旋转位置编码，通过旋转矩阵把相对位置编码进注意力，LLaMA 等在用。
  • KV Cache：生成时缓存历史 K/V，避免重复计算，大幅加速解码。
  • FlashAttention：优化注意力计算的 HBM 读写（IO 优化），不改变数学结果但显著提速省显存。
  • MoE：混合专家，每次只激活部分专家，扩大参数的同时控制计算量。
能答上任意一个都是大加分项，建议至少准备其中两个。

生成式模型与扩散模型

1. 生成式模型谱系

模型核心思想优劣
VAE编码器学潜在分布，解码器重建，ELBO 训练稳定、可插值；生成偏模糊
GAN生成器 vs 判别器极小极大博弈清晰锐利；训练不稳定、易模式崩塌
扩散 / DDPM逐步加噪再学去噪（反转 Markov 链）质量高、稳定；采样慢（多步）
流模型可逆变换精确似然似然精确；结构受限

2. 扩散模型（DDPM）直觉

  • 前向（加噪）：按预定方差_schedule 逐步往数据加高斯噪声，约 $T$ 步后变成纯噪声。
  • 反向（去噪）：训练网络 $\epsilon_\theta$ 预测每一步加入的噪声，推理时从噪声出发逐步去噪生成样本。
  • 训练目标：简化为预测噪声的 MSE：$L=\mathbb{E}\big[\|\epsilon-\epsilon_\theta(x_t,t)\|^2\big]$。
💡 为什么扩散模型这么强

它把"一次性生成复杂分布"拆成"很多步简单的去噪"，每一步都是易学的回归；配合 U-Net 与良好的噪声 schedule，既稳定又能产出极高保真度样本——这正是 Stable Diffusion / Sora 的底层的思路。

🔍 具体解释：DDIM 如何加速采样

标准 DDPM 需约 1000 步迭代，慢。DDIM 把 Markov 链改成非马尔可夫的确定性过程，可在 20~50 步内得到近似同质量样本——用"牺牲随机性换速度"的思路大幅提速，是实用扩散模型的标配。

🌈 生成式模型面试题

对比GAN 和扩散模型的区别？▼
GAN 用对抗训练一次生成，快但易不稳定/模式崩塌；扩散模型用"加噪-去噪"多步生成，更稳定、质量更高，但采样慢（需多步迭代，DDIM 等可加速）。
原理扩散模型的训练目标是什么？▼
前向逐步加高斯噪声，训练网络预测所加噪声，损失是预测噪声与真实噪声的 MSE（等价于变分下界 ELBO 的简化）。推理时从纯噪声出发反复去噪得到样本。
加速怎么加速扩散模型的采样？▼
① DDIM 用确定性非马尔可夫过程减少步数；② 知识蒸馏（Consistency Models）一步/少步生成；③ 潜空间扩散（如 Stable Diffusion 在 VAE 潜空间而非像素上扩散）降低维度。
VAEVAE 的 ELBO 是什么？▼
证据下界 $\log p(x)\ge \mathbb{E}_{q(z|x)}[\log p(x|z)] - KL(q(z|x)\|p(z))$：第一项是重建项（解码像不像），第二项是正则项（潜变量逼近先验）。训练即最大化 ELBO。
🧠 第 10 步

大模型进阶：RLHF / RAG / Agent

Transformer 之后，大模型（LLM）的能力来自"预训练 + 对齐 + 工具调用"三件套。

1. 预训练与微调

  • 预训练：海量语料上自回归预测下一 token，获得通用语言能力。
  • SFT（监督微调）：用指令-回答数据教模型"按指令办事"。
  • LoRA / QLoRA：低秩适配，只训练小矩阵即可微调，省显存。

2. RLHF（人类反馈强化学习）

$$ \max_\pi\; \mathbb{E}_{x\sim D}\big[\,r_\phi(x,y)\,\big] - \beta\, KL(\pi_\theta(y|x)\,\|\,\pi_{ref}(y|x)\big) $$
  1. 训练奖励模型

    用人类对回答的偏好排序训练 $r_\phi$。

  2. PPO 优化

    以奖励模型为信号、KL 约束防跑偏，强化学习微调策略。

  3. （替代）DPO

    直接偏好优化，绕过显式奖励模型，更简单稳定。

3. RAG（检索增强生成）

  • 流程：问题 → 向量检索相关文档 → 拼进 prompt → 让 LLM 基于检索内容回答。
  • 解决知识过时、幻觉、私有数据问题；关键在切分、向量库（如 FAISS）与重排。

4. Agent（智能体）

  • 让 LLM 调用工具/函数、做规划-反思-执行循环完成多步任务。
  • 组件：规划（任务分解）、记忆（短期/长期）、工具（搜索/代码/API）、反思（自我纠错）。
  • 代表范式：ReAct（推理+行动交错）、Reflection（反思迭代）。
💡 和你的科研结合

你做图神经网络金融反欺诈，可谈：用 GNN 做特征/检索、用 LLM-Agent 做可解释风控决策、用 RAG 接入法规知识库——把前沿大模型能力与你的方向结合，是导师很看重的"交叉创新"点。

🧠 大模型进阶面试题

对齐RLHF 是什么？为什么需要它？▼
用人类偏好训练奖励模型，再用强化学习（PPO）让模型输出更符合人类期望。预训练只学"像文本"，RLHF 让模型"有用、无害、诚实"。DPO 是更简单的直接偏好优化替代。
RAGRAG 解决了 LLM 的哪些问题？▼
缓解知识过时（训练截止）、幻觉（无依据的编造）、无法访问私有数据三大痛点。流程是检索相关文档→拼进上下文→生成，依赖好的切分、向量检索与重排。
微调LoRA 为什么省资源？▼
冻结原权重，只在每层旁插入低秩矩阵 $BA$（$r\ll d$）训练，可训练参数仅约原模型的 0.1%~1%，显存与存储大幅降低，且可多适配器热插拔。
Agent什么是 LLM Agent？核心组件？▼
能自主调用工具、规划并反思完成任务的系统。核心：规划（拆任务）、记忆（上下文/长期）、工具（搜索/代码/API）、反思（自我纠错）。ReAct 让推理与行动交错进行。
⚡ 第 11 步

Transformer 工程优化与推理加速

模型训得出来还要跑得动。面试常问：长序列怎么省显存？推理怎么提速？MoE 是什么？

1. FlashAttention

标准注意力需把 $N\times N$ 注意力矩阵写回 HBM，IO 贵。FlashAttention 在 SRAM 内分块计算并在线归一化，不显式构造大矩阵，IO 量从 $O(N^2)$ 降到近似线性，显存与速度双优——是当今 LLM 标配。

2. KV Cache

自回归生成时，每新生成一个 token 都要重算前面所有 token 的 K/V。KV Cache 把历史 K/V 缓存起来，避免重复计算，推理延迟从 $O(n^2)$ 降到 $O(n)$（随序列线性增长），是解码加速的关键。

3. 量化与蒸馏

  • 量化：FP16/BF16 → INT8/INT4，压缩显存、提速，需兼顾精度（如 GPTQ、AWQ）。
  • 知识蒸馏：用小模型学大模型输出（软标签），在边缘端部署。
  • 剪枝：去掉不重要的权重/头，稀疏化。

4. MoE（混合专家）

$$ y = \sum_{i=1}^E G(x)_i\, E_i(x),\qquad G \text{ 为稀疏门控} $$

每个 token 只激活少数专家（如 8 选 2），参数量巨大但单次计算量可控，是 Mixtral、GPT-4 等大模型扩展能力的主流结构。

⚡ 工程优化面试题

注意力FlashAttention 为什么更快更省显存？▼
标准注意力把 $N\times N$ 矩阵写入 HBM，IO 昂贵。FlashAttention 在高速 SRAM 内分块计算并在线 softmax，不 materialize 大矩阵，IO 从平方级降到近线性，既省显存又提速，且数学结果一致。
推理KV Cache 是什么？为什么能加速解码？▼
自回归生成每步都要历史 K/V，KV Cache 把已算的 K/V 缓存，免去重复计算。虽随序列变长显存增长，但把每步复杂度从 $O(n^2)$ 降到 $O(n)$，是 LLM 解码提速的关键。
压缩模型量化是什么？有什么取舍？▼
把权重/激活从 FP16 降到 INT8/INT4，显存与带宽大幅下降、推理更快，但可能损失精度（需校准/混合精度）。常用 GPTQ、AWQ 等保持可接受精度。
MoEMoE 混合专家模型的核心思想？▼
每层含多个专家前馈网络，由门控网络给每个 token 只选激活少数几个（如 8 选 2）。参数量可以很大，但单样本计算量只略增，从而在可控算力下大幅提升模型容量——是主流大模型扩展范式。
